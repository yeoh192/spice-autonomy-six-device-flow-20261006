扩展版本0.2.6-fixture-repair；保留原测量依赖字节，以核验并复用已通过校准。新增两个通用模块及统一CLI repair-drafts，未硬编码器件规格、电路或引脚。原任务、模型、索引库和全覆盖门禁保留。

## 一次启动的流程

阶段证据 → Qwen选择受限动作 → 程序校验并生成实际电路 → GLM前审 → 两种独立已知网络校准 → 参考模型真实试运行 → 辅助接地敏感性检查（如适用） → GLM后审 → 保留或回退。

前审仅要求物理条件、端口、测量和范围成立。实测结果只在后审出现；不能因为结果尚未产生就拒绝前审。程序从实际电路AST提供电源两端与数值，解析包装模型的端口位置映射，并对手册中同一端子的物理引脚组提供候选映射证据。映射证据仍由独立审查核对；不会单凭模型省略同端子引脚而推断少了绕组。

失败自动反馈，包括失败阶段、实际候选、程序事实、审查意见和实测诊断。有缺口时自动按白名单补读原手册页、端口、提取电气数据及证据目录；参数非法也返回修订。每项最多三轮，不需要人工转发意见。程序事实不能替代独立审查；意见冲突必须再次审查，而非自动批准。

## 当前动作与边界

允许选择trap/gear、细化DC或瞬态步长、为既有节点添加1GΩ至1TΩ的高阻参考。高阻参考必须额外使用十倍或十分之一阻值对照，标量相对差不超过1e-4（绝对误差下限1e-12）才可保留；该数值是夹具数值扰动检查，不修改器件验收阈值。

温度、端口、原始元件与激励、频率/扫描端点、测量定义、参考数据和规格均锁定。不执行Agent提交的Python或shell，不接受任意protocol替换。这是已实现的受限动作库，并非任意执行器自动开发。动作不足、资料缺失或预算耗尽仍会输出具体缺口。

模型规格不符与方法失效分开。参考模型仅验证接口；规格偏差进入model_repair_queue，当前缺少实际建模候选时明确记录candidate_model_required_before_model_repair，禁止修改参考模型来制造通过。六器件候选建模和完整手册覆盖仍未完成，不会把本次结果算作六器件完整流程验收。

预检核对用户的20项真实校准及其代码、运行器和RAW；旧测量依赖没有改变时无需重跑。核验上轮资格账本、请求文件与真实RAW后，可复用3项已有资格、迁移7项真实仿真。新增调度代码导致缓存签名改变时，执行依赖一致性检查后建立显式migration.json，不直接信任旧路径或completed文字。旧记录保持不变。
