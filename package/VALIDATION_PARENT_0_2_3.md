## 本版故障验证

测试注入相反方向的曲线残差，确认即使平均有符号误差为零，分区偏高/偏低和峰值仍提供给Agent。典型值偏差与规格越界分开记录；零跨度不会伪造归一化误差。参考CSV或已测电路被改动时阻止共享证据使用。

优化Agent与独立审查取得相同活动模型、固定目标与证据哈希；补丁回退/保留反馈也携带候选残差。历史上下文保留方向摘要及抽样点，完整曲线仍存本地。瞬态使用边界插值与按时间积分的均值，终点之后的波形独立标记，越界时间窗拒绝。

“尚无未来实测结果”的审查反馈自动返回提案审查，没有调用数值夹具调整。预审通过后才校准、试运行并进行实测资格审查。真实实测方法缺陷或错误协议哈希仍阻止登记；单通道通过不会清除封装范围缺口。有效测量得出不合格电气值时，保留该模型偏差，不能把它误当作测量方法无效。

无B源的已知电阻模型由Qwen模拟角色选择25%以内参数对照，程序执行、审查后提交同补丁完整回归，成功保留。另一个故障案例中该修改损害已有通过项，完整回归回退。数值节点、模型类型/Level、非零值符号及跨子电路节点修改均被拒绝。这些采用模拟Agent与解析波形验证控制流，不证明真实Qwen或GLM会提出同一正确方案。
