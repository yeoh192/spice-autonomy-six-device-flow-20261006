# UC2845 扩展输入包

本包使用用户提供的 TI UCx84x 中文手册，选择 UC2845、8引脚功能接口；14引脚版本不可直接替换。保留原12项测试，新增19项，共31项活动测试。新增电路和测量接口接入统一候选选择、测试、模型优化、审查、回归、保留/回退与报告流程。

## 输入及范围

- task.json：flow-1统一入口，31项协议、冻结的条件与验收标准、路由及预算。
- manual/uc2845.pdf：完整61页来源；references/electrical.json保留电气表39条记录。
- inventory.json：52条首轮范围记录（39条电气表、10幅典型图、3项约束），不宣称全61页穷尽。
- circuits/：31项活动电路、共享model.lib以及PWM功能演示网表。
- models/UC2845_initial_candidate.lib：独立构建的初步行为候选，不是TI模型或已通过拟合的模型。
- acceptance.json：典型值10%、曲线归一化MAE5%、最大误差10%；手册最小/最大限值仍执行。
- evidence/：本版测量校准与器件执行检查；manifest.json校验输入文件。

新增19项：参考电压线性/负载调整率、振荡频率、输出开关频率、振荡幅值、最大/最小占空比、UVLO启动/关断阈值、输出上升/下降时间、电流检测传播延迟、四项20mA/200mA输出高低电压、电流检测阈值、误差放大器低频增益、反馈输入电压。

原12项为参考电压、COMP源/灌电流、高低电平、启动/运行电流、参考短路电流、两项输入偏置电流及两个温度端点参考电压。偏置电流的负电流表格解释尚待复核。

## 方法与模型的边界

新的通用测量接口覆盖完整周期频率/占空比、实际波形10–90%边沿、触发延迟、事件处偏置与区间变化量。每种接口提供两个不同解析夹具；没有完整边沿、周期、预置条件或输出时，报告测量错误。

UVLO采用VREF跨越2.5V时的VCC作为代理，输出边沿采用项目10–90%定义，误差放大器用10Hz增益近似直流增益。这些方法说明随协议提供，仍需独立物理资格审查；运行成功不能替代方法资格或器件验收。

初始模型采用固定52kHz振荡和三角波、平滑PWM近似，仅支持首轮RT=10kΩ/CT=3.3nF条件；尚未真实实现外部RC依赖、逐周期锁存、准确传播延迟、温漂、噪声、热和寿命模型。新增EDGE_SOFT参数只暴露原有平滑常数，初始数值保持0.01。测试失败应触发模型迭代，不以放宽标准替代修复。10幅典型曲线尚未数值化，完整手册覆盖仍未完成。
