## 运行

```bash
bash RUN_GPT_CORRECTED_TESTS.sh --check-only
bash RUN_GPT_CORRECTED_TESTS.sh --run
```

校验实际库证据后生成flow-1任务，再按顺序使用spice_flow.py运行。当前入口不调用API、不放宽验收、不拟合参考模型。单器件finished_with_gaps退出码2是预期范围状态，批次只在该明确状态时继续，不忽略真实程序错误。

本包是原用户macOS环境快照，依赖指定LTspice启动器和保留的绝对证据路径，并非跨机器可移植安装版。旧五器件运行目录与原输入未修改。库资格按证据逐项核对；证据篡改、模型变化或校准失败会拒绝登记。未来候选模型仍需重跑校准和完整活动回归。
