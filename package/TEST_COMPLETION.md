# 五器件测试能力补齐入口

目标：在冻结的器件输入包和验收标准下，让软件整理条件、设计电路、独立审查、执行已知电路校准、执行参考接口试运行、实测资格审查，并回写方法收据。该阶段不把参考模型拟合成正式交付模型。

已修正的实际失败：
- 电容参考模型按记录/温度选择，不再因三个温度入口而整体阻塞。跨温度比值保留独立多次测量能力缺口，禁止用单温度模型替代。
- ACS723外部依赖由模板库白名单文件展开，记录源文件哈希；所选20AB灵敏度仅由该型号手册记录换算，极性配置引用打包符号证据。这是参考接口配置，不是拟合候选，更不是独立测得的灵敏度。
- 将真实源模型、端口证据、精确协议字段、程序解析的接线以及前后审查阶段要求发送给条件整理、设计和审查角色；不再让角色依据空接口猜测字段或把未来校准结果当作启动前提。
- 增加支路电流采样独立校准，适用于反向漏电及电源电流。已有电压、交流及电荷校准继续使用真实原语。
- 每条记录隔离工作流检查点，复用器件共同的请求缓存和总预算；不同温度的模型不会覆盖彼此。
- 另外五个器件的全部可整理队列进入调度，目前120条：二极管6、电容7、变压器2、传感器19、运放86。原来的每器件6条截断已解除。全部清单记录及缺数据、缺解析器、既有绑定待审计仍保留。

运行：`bash RUN_FIVE_TEST_COMPLETION.sh --run`。默认不带参数只离线预检。两个Key由终端隐藏输入，设计模型qwen3.8-max-0902，审查模型glm-5.3。若终端环境仍有旧DASHSCOPE_API_KEY，可在启动时使用`env -u DASHSCOPE_API_KEY -u GLM_API_KEY bash RUN_FIVE_TEST_COMPLETION.sh --run`以重新隐藏输入。

按实际可整理队列计，每项API总预算最多18次，120项合计最多2160次，仿真最多1440项，每器件2小时。14项草案修复另有预算；这是上限，不是预计消耗。达到预算输出剩余缺口，不放宽标准，不把本次未测的记录算为通过。

安装在新目录。历史校准文件和已存在资格证据仍由启动脚本引用你本机路径。启动器先为当前版本执行20项交流校准，资格修复引用本轮校准。旧资格只有在校准身份一致时复用，否则重新审查与试运行；原记录保留，不绕过哈希验证。中断后执行新目录的RESUME_FIVE_TESTS.sh。输入、路由、代码或预算变化时新建任务，不跨版本强制复用缓存。

本版本仅做离线验证，真实API/仿真资格待用户执行。120项条件整理不等于120项合格测试；剩余波形解析、噪声、可靠性、热学及未数字化参考曲线不假装完成。正式候选建模、全活动回归及六器件完整交付仍须后续验收。
