# 持续验收主调度器

通过任务policy.continuous_until_acceptance=true，或统一run/preflight命令的--continuous启用。旧批次默认有界行为保持兼容；UC2845新启动器默认启用持续验收。

主调度器掌握结束权。局部defer、审查拒绝、回退、分析次数及试验次数耗尽只结束一批调度，自动进入下一批；每批保留历史、累积物理调用量和故障证据。计数和总时间不再作为持续模式的停止条件，但HTTP超时、单项仿真超时及有限局部尝试仍保留，防止一个子步骤占住流程。

成功交付要求所有活动测试完成且pass、已声明清单完成审阅与绑定验证、来源策略满足。资料缺失（缺机读条件、参考曲线或判定依据）保存为paused_missing_information；Ctrl+C保存为interrupted。两者都不表示成功。不能保证模型一定收敛。

一项执行/偏置检查失败不阻塞其他已完成测量的优化。受限模型修改经提案审查、全部活动测试尝试和结果审查后，允许保留局部改善的工程候选；已有失败项仍为not_evaluated。新增执行失败、已通过指标退化或完整回归缺项禁止保留。不得修改冻结的参考值、手册条件、端口或验收阈值来换取通过。现有夹具修复入口仍受合同约束；主流程将冻结夹具故障及真实电路证据交给模型/故障诊断，未声称能修复任意执行器代码。

API传输、认证、配置错误采用最长30秒退避后继续重试；实际长期认证错误需要平台/凭据恢复，程序会等待，Ctrl+C可结束。格式/接口错误先局部修订，再交回主循环。缓存损坏或框架异常保存证据并等待修复，不伪装成缺资料、仿真成功或已交付。没有真正进展的无限循环是可能的，使用者可主动停止。

断点包含master的phase/cycle、模型、测试结果和累计用量。相同输入、代码与路由用相同runtime加--resume；升级软件不能直接打开旧代码身份的断点，必须使用新输出目录。原实验不覆盖。

UC2845的31项接口及16项LTspice校准一并打包。参考资料/方法资格仍有缺口：启用持续模式不会凭空补出数字化曲线或使初始模型达标。本版只做离线故障注入和执行器回归；真实API持续验收需用户启动。

## 请求证据与响应保存（0.3.11）

优化和审查请求移除重复的 cases/results，模型正文统一引用 shared_evidence.model.text。优化每轮最多展开六项未通过项目的详细电路，按 master_cycle 轮换；全部测试 ID、结果和验收目标仍保留，候选仍执行完整回归。完整输入与发送上下文保存到 request_contexts，原始证据继续保存在本地。

发送前检查上下文不超过 90,000 UTF-8 字节（不是 token 数）。超限时不调用 API，返回 request_context 错误，需要进一步缩小上下文。

每次请求在解析、截断判断和合同校验之前保存已收到的 provider_response.txt；可解析时另存 raw_response.json，以及平台实际返回的 content.txt、reasoning_content.txt 等文字字段。已知密钥会脱敏。当前仍为非流式请求，无法查看服务端尚未返回的内容，也无法恢复旧版本丢弃的正文。

本次只完成离线验证，不代表第三方网关稳定性已经验证。代码升级后使用新的输出目录；旧运行目录保留作证据，不直接使用 --resume 跨代码版本续跑。

### 截断恢复（0.3.12）

遇到 finish_reason=length 时，将平台/模型对应输出上限持久化到 response_profiles，依次升至8192、16384、32768。后续逻辑请求和同版本续跑复用此配置，不同模型隔离。优化请求只要求一个具体修改，截断后只展开一项问题电路，其余验收目标保留。32768是当前恢复上限，不保证所有模型支持或足够；第三方思考控制参数尚未验证，因此不发送未经确认的厂商参数。本次没有调用真实API。

### 有限模式分类恢复（0.3.14）

UC2845默认有限模式下，每个逻辑请求将length截断与transport故障分别计数，各允许两次重试；第三次同类失败停止。格式/合同修订仍最多两次失败。计数保存到请求记录，同版本续跑不会重置。总API与时间预算始终优先，异常中断另有单请求7次物理调用保护上限。连续模式的显式选择行为不变。离线测试覆盖交替故障后成功、重复进入不重置和总预算先耗尽；未调用真实API。

### BUK请求大小恢复（0.3.15）

请求超限时，在发送前移除重复/采样曲线细节，保留全部测试ID、冻结目标、误差均值和关键峰值。完整证据仍存本地；详情缩减后的请求仍超过90KB则报告request_context并停止，不消耗后续提案修订次数。BUK65项历史证据离线复现请求从104651字节降至88168字节；未进行真实API认证或优化验证。
