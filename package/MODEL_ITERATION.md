# 批次模型迭代
新增阶段在测试开发和草案修复之后执行。固定活动测试、参考值、手册条件、端口与验收标准，Qwen修改参数/结构，GLM审查实际差异，每个候选完整回归，确认改善且已通过项目不退化才保留，否则回退并反馈下一轮。普通优化最多3轮，诊断修复最多3轮，预算共享。
目前BUK23项与1N4148六项进入模型迭代。其他4器件缺正式建模候选或有资格的活动测试，明确阻塞；不会把参考模型当成新建模成果。新增参考接口方法尚未获得正式候选资格，不能直接并入交付回归。整个器件手册覆盖仍单独审计。
旧仿真仅在模型、实际电路、运行器、解析器签名、原文件哈希以及真实成功状态均匹配时复用；原模型和状态不修改。新模型输出engineering_candidate.lib，缺口未闭合不称正式交付。
RUN_MODEL_ITERATION.sh可为当前已跑批次单独执行新阶段，无需重新做前面的API测试开发。RUN_SIX_DEVICES.sh为新任务自动包含新阶段。真实API和仿真由用户启动。
