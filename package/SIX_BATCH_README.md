# 六器件现有阶段批次包
本包不是六器件全覆盖自动建模完成版。一次启动串行执行BUK23项、1N4148六项配置回归，随后执行电容/变压器14项草案的自动反馈、受限电路修订、独立审查、校准与试运行。ACS723和ADA4528无可执行测试，明确记录阻塞；不会伪造通过或修改验收标准。
Qwen模型qwen3.8-max-0902，GLM模型glm-5.3。密钥只保留于进程环境。包含索引模板库、测试库、六器件资料快照。当前版本没有任意新解析接口开发能力，配置回归阶段使用现有模型，不重新索引选模或全覆盖拟合。
历史资格复用使用原资格目录，后续修复得到的8项不会无证据直接登记，本轮可能重新验证部分方法。原实验不改动。
这是当前Mac的本地安装包，依赖脚本列明的历史校准、资格目录和LTspice运行器，不是可移植GitHub发行版。
报告runs/six_batch/summary.json。finished_with_gaps不代表六器件验收通过。子阶段失败仍继续其他器件并保存返回码。中断后在打印的工作目录执行同一six_batch.py命令，加--resume；输入/代码变化可能使子阶段拒绝续跑。
